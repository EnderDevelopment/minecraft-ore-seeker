# OreSeeker

OreSeeker is a Minecraft mod that allows players to find ores in the world by pressing a key. After pressing the key, a menu appears where players can select the type of ore they want to find. The mod will then highlight the locations of the selected ore in the world. This mod is useful for players who want to efficiently gather resources in Minecraft.

## Install

1. Download the latest version of OreSeeker from the [releases page](https://github.com/enderdevelopment/orefinder/releases).
2. Place the downloaded `.jar` file into the `mods` folder of your Minecraft installation.
3. Launch Minecraft and ensure that the Fabric mod loader is installed.

## Use

1. Launch Minecraft and load a world.
2. Press the `F` key to open the Ore Finder menu.
3. Select the type of ore you want to find from the menu.
4. The mod will highlight the locations of the selected ore in the world.
